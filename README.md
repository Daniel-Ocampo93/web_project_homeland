# Tripleten web_project_homeland

## Descripción del proyecto
Este proyecto presenta una página web sobre diferentes lugares del mundo donde viven y trabajan los empleados de Practicum. La página incluye un imagen e información sobre distintas ciudades.

## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Diseño responsivo
- Metodología BEM

## Enlace al proyecto
https://daniel-ocampo93.github.io/web_project_homeland/

## Funcionalidades
- Diseño responsivo que se adapta a diferentes tamaños de pantalla (320px, 768px, 1280px)
- Navegación fluida entre secciones
- Optimización para diferentes dispositivos (escritorio, tablet y móvil)
